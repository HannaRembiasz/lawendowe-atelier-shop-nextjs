# 💜 Lawendowe Atelier — Headless E-commerce

Lawendowe Atelier is a headless e-commerce application I'm developing for my own business.

The project combines a custom storefront built with **Next.js** and **React** with **WordPress and WooCommerce** as the backend.

My goal is to create an online store tailored to my business needs while gaining practical experience in developing and integrating e-commerce functionality.

> **Project Status:** Work in progress. The application is not yet production-ready.

## 🌐 Live Demo

**[View Lawendowe Atelier Demo](https://lawendoweatelier-demo.vercel.app/shop)**

The demo showcases the storefront and its main shopping features.

**Note:** User registration and login are not available in the public demo.

## ✨ Features

### Implemented

- **Product Catalog** — displaying products and categories from WooCommerce
- **Category Filtering** — browsing products by category
- **Shopping Cart** — adding products and updating quantities
- **User Authentication** — customer registration and login
- **Account Management** — editing customer account information
- **Contact Form** — allowing visitors to send inquiries

### In Development

- **Checkout** — completing the order process
- **Shipping Options** — selecting delivery methods

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **WordPress** — customer accounts and REST API
- **WooCommerce** — product catalog and e-commerce backend
- **Zustand** — state management
- **React Hook Form + Zod** — forms and validation

## 🏗️ Architecture

The project uses a **headless e-commerce architecture**, separating the custom storefront from the backend.

- **Next.js** handles the user interface and application API routes.
- **WordPress** provides customer account management through its REST API.
- **WooCommerce** manages product data and e-commerce functionality.

This approach allows me to build a custom shopping experience while using WordPress and WooCommerce for backend operations.
